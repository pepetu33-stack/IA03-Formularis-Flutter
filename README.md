## Com executar-ho

Cada carpeta és un projecte Flutter independent. Les carpetes de plataforma (`android`, `web`, `windows`) no s'han pujat perquè Flutter les genera automàticament:

```bash
cd act3_form_c
flutter create .
flutter pub get
flutter run
```

Provat amb Flutter 3.47.5 / Dart 3.13.4.
